# Local LLM Hugging Face

Use this skill when changing local model loading.

- Load local models downloaded from Hugging Face.
- Support `llama-cpp-python` with GGUF files.
- Support `transformers` with local model folders.
- Do not use LM Studio.
- Do not use Ollama.
- Do not depend on external inference servers.
- Keep mock mode available when no real model is installed.
